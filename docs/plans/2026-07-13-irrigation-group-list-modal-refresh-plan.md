# 관수그룹 목록 모달 최신화 계획

## 배경

`관수그룹 생성`은 구역 FK 기반 관수그룹 마스터 생성 구조로 전환되었지만, 목록 팝업은 아직 `그룹 목록` / `deviceGroups` / 장치 그룹 / 장치 수 / 포함 장치 중심으로 남아 있다.

## 문제 요지

1. 버튼 라벨은 `관수그룹 목록`으로 표시되지만, 실제 팝업 메타 정보는 `그룹 목록`이다.
2. 목록 데이터 소스가 `settingsData.deviceGroups` 기준이다.
3. 상세 필드가 `그룹명`, `그룹 유형`, `장치 수`, `포함 장치` 중심이라 최신 관수그룹 생성 필드를 반영하지 못한다.
4. 관수그룹 생성에서 추가된 `관수방법`, `관수방법 상세`, `순환 방식`, `배액 재활용`, `토출구 수`, `기준 유량(L/h)`, `배드 수`, `운영 메모`가 목록 상세에 보이지 않는다.

## 작업 계획

1. 팝업 메타명 변경
   - `그룹 목록` → `관수그룹 목록`
   - subtitle/type도 관수그룹 마스터 기준으로 변경한다.

2. 데이터 소스 변경
   - 기존 `settingsData.deviceGroups` 사용을 중단한다.
   - `settingsData.irrigationGroups`를 기준으로 목록 row를 생성한다.
   - 구역명은 `settingsData.zones`와 `zoneId`를 매칭해 보강한다.

3. 목록 컬럼 최신화
   - 기존: `그룹명`, `그룹 유형`, `구역`, `장치 수`
   - 변경: `관수그룹명`, `관수방법`, `구역`, `토출 기준`

4. 상세 패널 최신화
   - `관수그룹명`
   - `구역`
   - `상태`
   - `관수방법`
   - `관수방법 상세`
   - `순환 방식`
   - `배액 재활용`
   - `토출구 수`
   - `기준 유량`
   - `배드 수`
   - `운영 메모`

5. 계약 테스트 보강
   - 팝업 제목이 `관수그룹 목록`인지 확인한다.
   - `irrigationGroups` 기반 데이터가 렌더링되는지 확인한다.
   - 최신 생성 필드가 목록 상세에 노출되는지 확인한다.
   - 옛 장치 그룹 중심 문구(`장치 그룹별 포함 장치`, `포함 장치`, `장치 수`)가 관수그룹 목록 모달에 남지 않도록 확인한다.

6. 검증
   - 관련 focused pytest 실행
   - JS syntax check 실행
   - 필요 시 전체 pytest 실행
