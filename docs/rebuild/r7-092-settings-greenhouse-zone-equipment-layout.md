# R7-092 Settings greenhouse/zone/equipment layout

Status: current baseline for `v1.15.49`.

## Required layout

```text
온실 정보, 구역 정보, 관수그룹 정보
온실 생성, 구역 생성, 관수그룹 생성
구역 목록—————————————————————
```

## Card rules

- `온실 기본 정보`, `구역 기본 정보` 헤드 부분 최우측에는 기존 공통 컴포넌트 카드처럼 상태 뱃지를 표시한다.
- 정보 카드의 상태 뱃지는 `renderR7CommonCardHeader` / `renderR7RecordCardBadge`를 사용한다.
- `온실 기본 정보` 바디는 `온실명`, `위치`, `설치유형`만 표시한다.
- `구역 기본 정보` 바디는 `구역 용도`, `면적`, `배드 수`만 표시한다.
- 기존 `구역 구성` 이름은 `구역 기본 정보`로 변경한다.
- `장비 구성`은 첫 번째 줄의 세 번째 카드로 둔다.
- `온실 생성`, `구역 생성`, `장비 생성`은 두 번째 줄에 이미지형 공통 카드로 둔다.
- `구역 목록`은 마지막에 full-width 공통 목록 패널로 둔다.
